lesson03 - 스프레드 / 나머지 매개변수 과제 실습

버튼을 클릭하면 콘솔과 화면에 결과가 출력됩니다.

1. 배열 복사

const arr = ["HTML", "CSS"];
const arrCopy = [...arr];
arrCopy.push("JavaScript");

console.log(arr);      // ["HTML", "CSS"]
console.log(arrCopy);  // ["HTML", "CSS", "JavaScript"]

2. 객체 병합

const book = { title: "책" };
const priceInfo = { price: 15000 };

const mergedBook = { ...book, ...priceInfo };
console.log(mergedBook);

3. 나머지 매개변수

function getMax(...numbers) {
  return Math.max(...numbers);
}

console.log(getMax(10, 5, 20, 8)); // 20
console.log(getMax(1, 2, 3));      // 3
