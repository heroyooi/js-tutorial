lesson06 - 클래스 & 상속 과제 실습

버튼 클릭 시 콘솔과 화면에 결과가 표시됩니다.

1) 기본 클래스 Book

class Book {
  constructor(title, author) {
    this.title = title;
    this.author = author;
  }
  info() {
    console.log(`제목: ${this.title}, 저자: ${this.author}`);
  }
}

2) 상속 활용 – EBook

class EBook extends Book {
  constructor(title, author, fileSize) {
    super(title, author);
    this.fileSize = fileSize;
  }
  info() {
    console.log(
      `제목: ${this.title}, 저자: ${this.author}, 파일 용량: ${this.fileSize}MB`
    );
  }
}

3) super 활용 – 부모 info() 호출

class EBook2 extends Book {
  constructor(title, author, fileSize) {
    super(title, author);
    this.fileSize = fileSize;
  }
  info() {
    super.info();
    console.log(`파일 용량: ${this.fileSize}MB`);
  }
}

(보너스) toString 활용

class BookPretty extends Book {
  toString() {
    return `📚 ${this.title} — ${this.author}`;
  }
}
