JavaScript 2회차 – 과제 풀이

개발자 도구 Console에서 결과를 확인하세요. (Windows: Ctrl+Shift+I, macOS: ⌥⌘I)

1) 사용자 정보 변수 선언

이름/나이/이메일을 let 또는 const로 선언하고 콘솔에 출력합니다.

2) 프로필 객체 생성 & 속성 변경

const 객체의 참조는 고정이지만, 내부 속성은 변경될 수 있음을 확인합니다.

3) typeof로 타입 점검

원시/참조 타입의 차이와 typeof null === "object" 이슈를 확인합니다.

보너스) 원시 vs 참조, 명시/암시 변환

값 복사/참조 공유의 차이, 숫자·문자열·불리언 변환을 실험합니다.

콘솔에 [STEP] 라벨로 구분해서 출력됩니다.
